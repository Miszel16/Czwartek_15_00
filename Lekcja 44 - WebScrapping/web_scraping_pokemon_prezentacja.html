Chwila… czym jest HTML?

HTML opisuje strukturę strony internetowej. Strona składa się z elementów zapisanych w znacznikach.

<div class="pokemon"> <h2>Pikachu</h2> <p>Electric</p> </div>

Dla Pythona to bardzo wygodne: może znaleźć konkretny znacznik albo klasę.

Nasze narzędzia 🔧

requests

Pobiera zawartość strony internetowej.

response = requests.get(url)

BeautifulSoup

Pomaga przeszukiwać kod HTML.

soup = BeautifulSoup( response.text, "html.parser" )

Szukamy elementów 🔎

find()

Znajduje pierwszy pasujący element.

name = card.find("a")

find_all()

Znajduje wszystkie pasujące elementy.

cards = soup.find_all( "div", class_="infocard" )
